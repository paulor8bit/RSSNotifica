# RSSNotifica ✨

Um aplicativo de desktop simples e fofinho para receber notificações dos seus feeds RSS favoritos! (´｡• ω •｡`)

## Funcionalidades (≧◡≦)♡

*   **Adicionar e Remover Feeds:** Adicione quantos feeds RSS você quiser e remova-os facilmente.
*   **Notificações em Tempo Real:** Receba notificações no seu desktop sempre que um novo post for publicado.
*   **Modo Escuro:** Uma interface escura e elegante para não cansar os seus olhinhos.
*   **Armazenamento Local:** Seus feeds são salvos localmente, então você não precisa se preocupar em perdê-los.

## Como Usar (๑˃̵ᴗ˂̵)و

Para rodar o RSSNotifica na sua máquina, siga os passos abaixo:

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/paulor8bit/RSSNotifica.git
    ```

2.  **Navegue até a pasta do projeto:**
    ```bash
    cd RSSNotifica
    ```

3.  **Instale as dependências:**
    ```bash
    npm install
    ```

4.  **Inicie o aplicativo:**
    ```bash
    npm start
    ```

E prontinho! Agora é só adicionar seus feeds e aproveitar! (ﾉ´ヮ´)ﾉ*:･ﾟ✧
